## My process

- Semantic **HTML5** markup
- **CSS Flex** for layout and centering
- Responsive design using **vh**
- Google Fonts for custom typography
- **Hover effects** and custom button styles

### What I learned

Here’s a small **CSS** snippet I’m proud of:

```css
body {
  display: flex;
  align-items: center;
  justify-content: center;
  height: 100vh;
}
```

This helped me perfectly center my card components on the screen and make it responsive on different devices.
